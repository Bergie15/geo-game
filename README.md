# Geo Game

A simple local multiplayer game built with React Native. Supports 6 players (1 human, 5 bots).

## Getting Started

1. Install dependencies:
   ```powershell
   npm install
   ```
2. Start the app:
   ```powershell
   npm start
   ```
   - For Android: `npm run android`
   - For iOS: `npm run ios`

## Features

- Local play with 6 players (1 human, 5 bots)
- Simple turn-based scoring
- Stubs for future multiplayer support

## Multiplayer (Future)

- Comments in code indicate where to add online multiplayer logic
